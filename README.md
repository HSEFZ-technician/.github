# HSEFZ Technicians

We are the **technical advisors** of the **EFZ Student Federation**.

HSEFZ-technician builds and maintains digital tools for campus activities, school services, and student life.

## Featured repositories

- [HSEFZ-digital-life](https://github.com/HSEFZ-technician/HSEFZ-digital-life): The latest version of HSEFZ digital services.
- [lucky-draw](https://github.com/HSEFZ-technician/lucky-draw): A lucky draw system for school performances and events.
- [Hashtag-EFZ-Homepage](https://github.com/HSEFZ-technician/Hashtag-EFZ-Homepage): Homepage project for Hashtag EFZ.
- [HSEFZ-Sports-Stats](https://github.com/HSEFZ-technician/HSEFZ-Sports-Stats): Sports statistics project for HSEFZ activities.
